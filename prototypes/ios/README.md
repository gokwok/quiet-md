# Quiet.md iOS 原型

原型锁定 `gpui-pre`、`gpui-pre-platform` 和 `gpui-pre-ios` 的 0.3.12。构建脚本把当前桌面源码复制到 `target/ios/stage`，再应用 [GPUI 适配补丁](port.patch)，直接编译整个桌面应用：`Workspace`、文档库、主页、侧栏、搜索、回收站、设置和编辑器都是同一份代码，并通过路径依赖共用 `fdl_core`。桌面 Cargo workspace 继续使用自己的依赖清单。

iOS 自己的代码在本目录，补丁里只留挂接点：

| 文件 | 内容 |
|---|---|
| `app.rs` | 入口（`crate::ios`）；手机版式的判断、安全区、抽屉、长按当右键、左缘返回 |
| `hub.rs` | 手机上的首页：搜索、收藏、所有文档、文件夹、最近删除 |
| `crop.rs` | 空间头像的裁切：选好图片后在方框里拖动、缩放，取方框里那一块（照 Craft），系统的滚动视图，存成不超过 512 像素见方的 PNG |
| `customise.rs` | 「自定义主页」：首页显示哪几栏、什么顺序，系统的表格放在系统的半屏面板里，存在 `NSUserDefaults` |
| `spaces.rs` | 空间（照 Craft）：首页左上的空间头像、设置顶上的「空间名 ⌄」和底部的换空间卡片、空间设置页、新建空间面板、「创建你的第一个空间」整页 |
| `files.rs` | 系统的文件选择器（`UIDocumentPickerViewController`）：选文件、选文件夹、把写好的文件存出去；选图片时先问「照片图库 / 文件」，照片图库是 `PHPickerViewController` |
| `alert.rs` | 确认框：系统的 `UIAlertController`，去掉它自带的压暗 |
| `folder_icons.rs` | 文件夹线性图标选项与旧标识的显示兼容，新建和更改图标共用 |
| `card.rs` | 「新建文件夹」的原生玻璃卡片：系统的输入框、按钮和菜单 |
| `style.rs` | 文档样式的画法：盖到主题上的文字 / 纸 / 字体，纸后面的背景，和纸胶带与涂鸦分隔符 |
| `veil.rs` | 首页与文档页共用的顶部 Liquid Glass，和滚动后出现的小字标题 |
| `toast.rs` | 顶上的玻璃提示胶囊（删除后带「打开回收站」入口） |
| `search.rs` | 手机上的整页搜索：输入框从页面上的搜索条滑上来，结果行带高亮、摘要和命中次数 |
| `appicon.rs`、`icons/` | 应用图标「页边」的三种底色（墨 / 墨绿 / 朱）：母版 SVG、打进包的 PNG（`icons/build.sh` 重出），和设置 › 外观里换图标的那一行 |
| `panel.rs` | 原生玻璃面板的控件：标题栏、分段、色点、行、缩略图、卡片 |
| `stylepanel.rs` | 「样式」面板的各页和动作（照 Craft 的文档样式） |
| `glass.rs` | 原生 Liquid Glass：把 `UIGlassEffect` 的视图盖在 GPUI 画面之上，和 GPUI 元素对位 |
| `shot.rs` | 退场：换页、收面板时用原生快照留住旧的样子，交给 Core Animation 送走；玻璃所在的那一层 |
| `keybar.rs` | 键盘上方的工具条 |
| `editor_surface.rs`、`EditorSurface.m`、`selection.rs`、`editor_panels.rs` | iOS 26 起的编辑浮层。UIKit 绘制玻璃、按钮、输入框和可滚动的列表，动作回到当前编辑器。 |
| `masonry.rs` | 只有文档的那一层的瀑布流：按标题和正文长短估卡片高度，放进较矮的那一列，只画屏幕附近的卡片 |
| `menu.rs` | 系统的弹出菜单：在 GPUI 元素的位置盖一个透明的原生按钮，挂上 `UIMenu`，菜单项被点后回到工作区 |
| `editmenu.rs` | 系统的编辑菜单（`UIEditMenuInteraction`）：对着选区弹出，项被点后回到编辑器 |
| `voice.rs` | 选中文字配音：编辑菜单里「配音」选角色，向 ElevenLabs 要带逐字时间的音频，存在文档库 `assets/voice/`；段落下一行播放，放的时候整段浅底、念到的那句深一档。角色或这段的「…」可开语气标签、改台词语言：先让快速模型写台本（加标签或译成英语、日语）再念，台本可展开看 |
| `touch.rs` | 什么时候出编辑菜单、里面有哪几项；块右侧的拖动标记和长按提起整块；块选中时的动作栏和选择圆圈；表格的单元格选择（作为 `editor` 的子模块编译） |
| `port.patch` | 上游 GPUI 的 API 差异，加上各处的手机版式分支 |

## 手机上的界面

宽度小于 700pt 时是单栏版式。更宽时走桌面的两栏版式，但 `Info.plist` 还没有声明 iPad，这条分支没有在设备上跑过：

- **按手机的习惯，不是缩小的桌面。** 主页和文档页都没有实心的顶栏：内容顶到屏幕上沿，从悬浮的圆钮和状态栏下面滚过（状态栏下有一道渐隐）。主页和文件夹页是窗口的浅灰底上浮着白色的卡片，页名是大标题，和工具行一起跟着内容滚走；顶上右边是新建文件夹（文件夹页左边是回上一级），卡片一直铺到屏幕下沿。文档页只有返回、目录和「…」三个圆钮；文档标题下面一道细线，紧接正文。打字时文档页右上角换成一个主色的「完成」，点了收起键盘。批量管理时和列表为空时，主页和文件夹页回到固定的标题栏。外壳的菜单（长按卡片或行、文档的「…」）从底部升起成动作面板，占满屏宽，下面压暗。菜单行和侧栏行 44pt，按钮 42pt，字号 16pt。手指抬起后不留悬停高亮。
- **首页是几个去处，不是文档库的平铺（照 Craft）。** 顶栏左边是当前空间的头像（点了去设置），右边一颗玻璃「…」，系统菜单里是「导入」（Markdown 文件、文件夹、DocxXML）和「自定义」。大标题下依次是搜索（「在〈空间名〉中搜索」，高 44 的胶囊）、快速访问（收藏的卡片横向排开，没有时是一块提示）、「所有文档」、可排序的各栏（「文件夹」：顶层的文件夹，带项数；「收藏」：收藏的文档一行一篇），最后一道通栏的线下面是「最近删除」（带篇数）和「自定义主页」。「文件夹」一栏右边的「…」是新建文件夹、折叠 / 展开这一栏；折叠只在这次运行里记着。
- **自定义主页。** 右上「…」的「自定义」或页尾的按钮打开系统的半屏面板（`customise.rs`）：快速访问（最上面那排卡片，横着拖，最多 10 张）选「最近使用」「收藏」或「无」，和下面「收藏」那一栏（列表）各管各的；「所有文档」可以隐藏；「收藏」「文件夹」两栏可以隐藏、拖动排序。改了马上生效，存在这台设备的 `NSUserDefaults` 里，不进文档库，各空间共用一份。
- **首页的滚动顶栏。** 大标题和搜索随内容滚走，空间头像和「…」钉在顶栏上不动（滚动后头像换成玻璃上面的一个系统视图，免得被玻璃糊掉）；向上滚动后顶部出现原生 Liquid Glass，大号「主页」的文字行完全进入顶栏后，居中的小标题才淡入；往回滚、文字行重新露出时小标题淡出。首页与文档页共用超薄磨砂加原生 Clear 玻璃，柔化经过的文字并保留背景色与边缘折射，底边是一道柔和的渐变高光。仅首页在深色时压低材质亮度，呈接近黑色的薄磨砂，只留微弱透色与底边；文档页保留原来的磨砂玻璃，不做这层压暗；居中的「主页」与首页「文件夹」使用相同的 18pt 系统粗体和文字颜色，不带光晕；文档标题滚出屏幕后也使用这层玻璃，不限于设置了背景的文档。浮层出现时玻璃让开，旧系统仍走原来的版式。
- **浏览页是同一套。** 「所有文档」（整个文档库里所有文档的平铺，不分层，不含文件夹）、「文件夹」（点首页那一栏的标题进，顶层的文件夹）和某个文件夹里，三页长得一样：左上返回，右上「选择」和「…」，大标题和一条搜索跟着内容滚走，下面是原来的网格 / 列表。「…」是一颗系统的玻璃钮，挂着系统菜单，分三组：新建文件夹（所有文档里没有）、宫格 / 列表、排序，当前的那项打勾。「选择」进批量管理：顶上左边是玻璃的「全选 / 取消全选」，中间「已选 N 项」，右边主色的 ✓ 收起；底部换成一条玻璃动作栏（创建副本、移动到、删除），没选东西时是灰的。
- **重命名在一张卡片里。** 手机上没有侧栏，新建文件夹和菜单里的「重命名」在屏幕上方弹出一张卡片，回车或点别处保存。
- **文件夹的图标可以换。** 长按文件夹，菜单里「更改图标」打开一组与默认文件夹同风格的线性图标；新建文件夹的图标菜单共用这一组 SVG，也跟随文件夹颜色。旧 emoji 标识只用于兼容读取，显示时转换为线性图标，无法对应的回退到默认文件夹，不批量改写文档库。选的图标记在文档库索引里（`Meta::folder_icon`，核心库的新字段），首页的文件夹行、文件夹页的标题和搜索结果都用它。桌面版还没有这个入口，也还不在文件夹卡片和侧栏上显示。
- **新建文件夹时可以填描述、选图标和颜色。** 手机上新建文件夹是一张原生的玻璃卡片（`card.rs`）。描述和颜色记在索引里（`Meta::folder_note`、`Meta::folder_color`，核心库的新字段；颜色是文档里用的颜色名）：描述显示在文件夹页的大标题下面，颜色染在列表里的文件夹图标上。建好之后还没有修改这两项的入口，桌面版不显示它们。
- **每篇文档可以有自己的样式。** 文档页「…」›「样式」：文字颜色、字体、纸的颜色、纸后面的背景（纯色、渐变、图片）、分隔符（线、和纸胶带、涂鸦），还有一个样式图库。样式记在索引里（`Meta::style`），不进文档文件；目前只有手机上能设、能看到。
- **底部没有标签栏，首页是唯一的起点。** 首页、文件夹和浏览页右下角只有一颗玻璃的新建按钮。首页「收藏」一栏照 Craft：标题的箭头进「收藏」整页（大标题、搜索、一块说明、卡片网格），右边「…」是收藏文档（系统半屏面板里列出文档，点一下收藏 / 取消，可搜索，`starpick.rs`）、自定义主页、折叠收藏；收藏的文档卡片在标题那一行末尾有一颗金色的星。首页「文件夹」里每个文件夹右边的箭头可以就地展开、收起（里面的文件夹还能再展开，每层缩进 16pt），点的时候轻震一下；点行的其余地方照旧进文件夹。设置从首页左上角的空间头像进；回收站是首页最后的「最近删除」，点进去和「所有文档」同一套：左上玻璃返回，右上玻璃「…」（清空回收站），大标题跟着内容滚走，下面是铺在底色上的行（图标、标题、还剩几天），长按「恢复 / 彻底删除」。两页都在主页这一摞里，左缘右滑跟手回首页；滑动时首页的顶部玻璃先收起，滑完再出来。主页不再拉抽屉（文档树和主页的卡片是同一份内容）。
- **设置从主页进入，不用侧栏。** 设置首页顶上是空间的大头像和「空间名 ⌄」，下面有「空间设置」「助手设置」「常规设置」；分类页使用居中页名和玻璃返回钮。页面是首页的底色，分组是不描边的卡片。可用左缘右滑返回上一级。
- **助手设置。** 按「文本」「语音」「图像」排列。语音页可以添加、替换或移除 ElevenLabs API Key（存放在当前设备的系统钥匙串中），用一排横向的模型卡片选择默认模型（初始为 Eleven v4）。「语音角色」是一排可横滑的圆头像；「添加」进入音色库，可搜索、按女声 / 男声 / 我的筛选，轻点一行试听，点星标收藏为本地角色。角色可以单独设置本地名称和头像，与 ElevenLabs 上的音色一一对应，不改动远端。换头像进「选择头像」：第一个圆从照片里选（裁成正方形），后面是 38 个自带头像（`avatars/*.webp`，只给语音角色用，编进二进制，不放在 `assets/` 里，免得桌面版也打包进去）。没换头像的音色用按 voice_id 生成的柔光球。试听放的是 ElevenLabs 托管的样音（请求不带 API Key，不花额度），用 `AVAudioPlayer` 播放，同一时间只放一个，离开语音的几页时停止。筛选、试听、换头像这些按钮在 iOS 26 起是原生 Liquid Glass。文本页配置 OpenAI 兼容的文本模型：上面两张并排的卡片是「主模型」（能力优先）和「快速模型」（速度优先），各自指向某个服务商的某个模型，两个可以来自不同的服务商。「服务商」可以添加多个（系统菜单里有 OpenAI、DeepSeek、OpenRouter、硅基流动，或自定义地址），每家一颗柔光球；点进去改名称、接口地址和 API Key（按服务商分开存在钥匙串里），或删除（同时删掉 Key、清空用着它的位置）。点卡片进第二级的模型列表：所有服务商的模型按服务商分组（向各家的 `/models` 要，多于八个时可搜索，也可以手动输入模型 ID）。模型给了 `reasoning_levels` 时，「推理强度」里多一行可选。「测试连接」给两个模型同时发一句 ping，收到第一个字就算通，写用时；不通就写服务自己的说法。协议、SSE 解析用 async-openai（byot，宽松读 JSON），网络是 reqwest + 系统 TLS，跑在一个单线程的 tokio 运行时上（`assistant_llm.rs`）；它不走 NSURLSession，所以 `http://` 地址不受 ATS 限制。图像页暂时留空。
- **Liquid Glass。** iOS 26 起，上面这些悬浮的按钮（新建、返回、目录、「…」）是系统的玻璃，折射的是下面滚过的内容，按下会缩一下；长按出菜单和点新建有触感反馈。玻璃跟应用自己的深浅色。更早的系统没有这个效果：仍是原来的实心顶栏、抽屉、标题下的搜索条和纯色的新建按钮。见下面「原生玻璃」。
- **底部面板是浮着的卡片。** 四周留 12pt，圆角 24pt，不描边。编辑器的面板（块菜单和叠在上面的子面板、添加面板、封面）顶上有抓手：按住往下拖，面板跟着走，拖过 80pt 松手就收起这一层（子面板回块菜单，块菜单回动作栏），不够就弹回（`touch.rs` 的 `pull_sheet`）。外壳的动作面板、键盘上方的各种工具栏没有抓手。
- **编辑器的块菜单和添加面板也是底部面板。** 块菜单从块动作栏的「格式」展开，只有类型、缩进和对齐、颜色（剪切、复制、删除和添加在动作栏上），类型图标六个一行、每格 44pt；「缩进和对齐」「颜色」点开后是叠在块菜单上面的另一张卡片，顶上一行返回，点块菜单露出的部分或面板外面都只收起这一层；添加面板贴在键盘工具条上方。面板出现时从下面升上来，最高只到悬浮的那排按钮下面；收起时滑出屏幕下沿。添加面板里「表格」「分栏」的尺寸选择器占满屏宽，点哪格就插入那么大的。
- **过渡。** 进文档、进文件夹（包括子文件夹）、首页的子页、设置的第二级：新页从右边滑入并淡入。返回时离开的那一页向右滑出（四角和屏幕一样圆，左边一道阴影；跟手时等下面那一页真的上屏了才开始跟，免得先露出旧页），从卡片打开的文档返回时不往右滑，而是跟着手指缩小、松手缩回那张卡片再淡出（照 Craft 和系统的缩放转场；卡片这期间空着一格，不在屏幕上就照常滑走），下面那一页带视差从左边回来、压着的一层暗渐渐褪去；只属于新页的玻璃等旧页走完再淡入。文档、文件夹、首页的子页、回收站和设置可以从左缘右滑跟手返回：松手过半（或往右甩）就滑走，不过半就滑回来、恢复原来那页（文档回来时键盘不会再弹出）。底部面板（外壳的动作面板、块菜单和它的子面板、添加面板、工具栏、链接等带输入框的面板）收起时滑出屏幕下沿，下面的遮罩一起淡掉。做法见 `shot.rs`：GPUI 只画当前状态，离开的东西是趁它还在屏幕上拍下的原生快照。
- **不描边，靠明暗分层。** 首页的行、文档卡片、底部面板不画 1px 的边：首页的行直接铺在页面底色上，行与行之间一道缩进的细线，节标题粗体；卡片是文档页铺满的圆角块（网格页边 12pt、间距 8pt）；深色下浏览页是纯黑，文档页是深灰；面板靠填充色和阴影。只在手机版式里这样，桌面照旧。
- **输入 `/` 插入。** 光标附近先显示分类；进入分类后可以返回，继续打字会筛选命令。菜单沿用编辑器的悬浮卡片。
- **链接、公式和代码。** iOS 26 起，链接在键盘上方确认。轻点公式打开独立编辑页，上方实时排版，下方用带行号的编辑器输入 LaTeX。点代码块进入代码编辑页，底部切换语言、复制代码或收起键盘，右上角勾号返回正文。
- **没有悬停手柄，整块的操作在右边。** 页边只有 20pt，块左边的手柄放不下。编辑时，光标所在的块第一行右侧有一个拖动标记（两道短横）：点它选中整块，按住它拖动就是排序。长按一个块直接把它提起来拖（照 Craft，编辑时也是）：没在编辑时不挪就松手是选中这一块；编辑时长按光标所在的块、不挪就松手也是选中它并收起键盘，长按别的块不挪就松手什么都不变；编辑时一拖动，编辑就结束。只读、标题、表格格子里长按仍是选词。落点、拖着的影子和拖到边上自动滚动用的是桌面版原有的那一套。添加和选中整块在键盘工具条上也有。
- **块选择。** 横滑普通段落或长按可进入块选择。点右侧的空心圈加选，点实心圈取消，可以隔行选择。沿右侧选择区向上或向下拖动可加选一段连续的块，同一次拖动折返可缩短范围，靠近上下边缘会自动滚动。正文区域仍可竖向滚动。文字选中时铺底色，图片、附件卡片、子页面卡片、代码和整表使用描边。可裁剪的图片、代码、表格在单选动作栏分别提供「裁剪」「编辑代码」「编辑表格」；多选时可剪切、复制、删除，右上角「✓」退出。
- **表格。** 单元格中的「⋮」可打开底部工具面板。「编辑表格」插入、移动或删除行列，「选择单元格」切换格、行、列，「格式」调整字形、对齐、字体和填色。主面板可以添加内容、插入公式、切换标题行列和重置列宽。排序按所选列文本进行，保留标题行；带跨行合并的表格不提供排序。
- **选文件、存文件用系统的面板。** 导入在浏览页右上角「…」的菜单里（Markdown 文件、文件夹、DocxXML），导到当前的文件夹；首页右上角「…」的「导入」里也有这三项。手机上导入文件夹只收这一层，子文件夹跳过。「下载为 Markdown」、图片和附件的「下载」先写到沙盒的临时目录，再弹出系统的「存储到」。插入图片和上传封面先问从哪里选：「照片图库」是系统的照片选择器（不用相册权限；HEIC 之类转成 JPEG 再存进文档库），「文件」是只列图片的文件选择器。
- **文字选区。** 双击选词后，键盘上方的平面工具条依次提供颜色、粗体、斜体、删除线、行内代码、链接、公式和收键盘；横滑可找到块类型、下划线和更多。
- **文档面板。** 从目录按钮或「…」打开，顶部切换目录、任务、附件和查找。查找模式菜单可展开替换栏，选项可切换文本或正则表达式、区分大小写、忽略变音符号和部分匹配。点结果跳回原文，箭头切换匹配项。
- **从主页开始。** 左缘右滑：文档、文件夹、回收站和设置回主页，设置的第二级回第一级。没有玻璃的系统上没有标签栏，侧栏仍是从左侧滑出的抽屉，主页左缘右滑拉出它。
- **安全区。** 顶栏在状态栏之下，内容避开 Home 指示条；键盘弹出时正文和浮层都收在键盘上方。状态栏的字跟着应用的深浅色走。
- **键盘工具条。** 输入正文时可以插入 `/`、打开块格式面板，或在「⋮」中撤销、重做和执行块操作。右端保留粘贴和收起键盘；使用硬件键盘时，工具条贴近屏幕底边。
- **编辑菜单。** 双击选词、只读时长按选词（可继续拖动），或在光标上再点一下，弹出系统的编辑菜单（剪切 / 复制 / 粘贴 / 全选，和别的应用里是同一条，位置和收起由系统管）。阅读模式下长按复制的代码已接上，尚未在模拟器里验证。
- **长按当右键。** 侧栏的行、主页的卡片、回收站的行，原本挂在右键上的菜单都由长按打开。
- **目录** 的按钮在顶栏，列表是临时浮层，选了标题就收起，不记进设置。
- 搜索、「移动到」、文档信息等对话框按屏幕宽度重排；回收站在窄屏不显示「位置」一列。页边距在窄屏是 20pt。

文档库在应用沙盒的 `Documents/Quiet.md`，首次启动放入「开始指南」。编辑后按桌面的节奏保存，进入后台时立即保存。

新插入的库内资源使用相对路径 `assets/…`，随空间一起移动。读取旧文档时，核心库也能在当前空间的 `assets/` 下查找原沙盒路径已失效的资源。详见[文档库格式](../../docs/FORMAT.md)。

### 原生玻璃

iOS 上 GPUI 的 Metal 画面是不透明的，桌面版「玻璃垫在画面下面」的做法用不了。这里反过来：`glass.rs` 把 `UIVisualEffectView`（`UIGlassEffect`）盖在 Metal 视图上面，折射的就是 GPUI 画的内容。玻璃和系统菜单的按钮放在 Metal 视图旁边、盖在它上面的一层透明视图里（`shot::overlay`，点到空处时它自己不接，触摸照旧落到 GPUI），不是 Metal 视图的子视图：退场的快照只拍 Metal 视图，不能把玻璃也拍进去。由此有三条约束：

- **玻璃上的东西必须是原生视图。** GPUI 画不到玻璃上面，所以图标是把资源里同一份 SVG 用 resvg 画成模板图交给 `UIImageView`，文字是 `UILabel`（系统字体）。带 GPUI 文字或会滚动的内容不适合放玻璃。玻璃菜单是一块作底的圆角玻璃（`glass::panel`）加几行没有自己玻璃的原生图标和字（`glass::row`）。
- **点击仍归 GPUI。** 原生视图不接触摸，点击落到下面同一位置的 GPUI 元素；GPUI 元素里放一个 `glass::pane(...)` 占位，把自己的位置交给同名的玻璃。
- **玻璃永远在最上层。** 抽屉、面板、对话框出现时由 `glass::begin` 全部藏起；元素不在画面里的玻璃在下一帧藏起。

**系统菜单**（`menu.rs`）是另一种叠法：出现时的变形、按住滑动时跟手的高亮都是系统做的，自己拼的玻璃做不出来。那个透明按钮自己接触摸，那一小块的点击不经过 GPUI；菜单项的回调来自系统，先排进 GPUI 的主线程队列，再进工作区（`ios::menu_action`）。菜单的样子、朝哪边弹、各项的顺序都由系统定，图标用 SF Symbols。首页「文件夹」一栏的「…」、首页和浏览页右上角的「…」是这样做的；后两者连按钮本身也是系统的玻璃钮，菜单从它里面变出来。

**自己接触摸的玻璃。** 新建按钮打开了玻璃的「可交互」（按下时的拉伸和高光是系统的），上面盖着透明的原生按钮接点击，同样经 `ios::menu_action` 回到工作区。这两处的点击不经过 GPUI。

类名和选择子都在运行时查找，没有 `UIGlassEffect` 的系统上 `glass::supported()` 为假。设 `SIMCTL_CHILD_QUIET_MD_IOS_NO_GLASS=1` 可以在新系统上看旧系统的版式。

### 还没有的

- 「下载为 PDF」和打印在 iOS 上没有。
- 导入文件夹时文件夹留在原地读（向系统要了访问权后不再交还）；其余选中的文件由系统拷进沙盒的临时目录再读。
- 多窗口、快速笔记、打印、自动更新在 iOS 上没有入口。
- 「开始指南」里那张四列的表格，第二、三列之间有一道约 10pt 的缝，原因还没查。
- 依赖悬停或拖动的控件还没有触屏替代：表格的行列手柄、图片缩放、侧栏和主页的拖动排序。
- 主页的标签行、设置页的控件仍是桌面尺寸。导出 Markdown 的设置对话框仍使用桌面版式（对话框里第二个选项在手机上被裁掉）。
- **过渡还差的。** 往里走时只有新页滑入，旧页不向左退（视差只在返回时有）。顶上的玻璃钮不在两页之间变形：返回时离开那一页的淡出，新页的等旧页走完再淡入。工具栏上方的下拉（类型、颜色、更多）出现时没有动画。快照和 Metal 新的一帧是两条路上屏的，模拟器上没看到闪，真机上要确认。
- 抽屉不能左滑收起。
- 普通输入时的键盘工具条沿用正文底色。设置的第二级仍是固定的标题栏，内容没有顶到屏幕上沿。
- 文件夹页里没有上级路径（只有回上一级的按钮）；在这个文件夹里新建用底部的「+」（新建文档 / 新建文件夹）。
- 有文件夹的那一层（文件夹和文档混在一起）仍是等高的网格，不是瀑布流。瀑布流的卡片高度是估的（缩略图里有图片、表格时会偏矮，多出的内容被裁掉）。
- 文件夹卡片上悬停才出现的「新建」「更多」两个按钮也不放，对应的操作在长按菜单里。
- 悬浮顶栏比桌面少了两样：文档标题和它前面的上级路径（原来点路径可以去上级文件夹，现在只能返回主页再进）。主页工具行的「批量管理」和批量管理里的「退出」在手机上只剩图标，没有文字；列表视图只留标题和一列时间。
- 目录按钮要等编辑器画过一帧才知道文档有没有标题：在实心顶栏的版式里，刚打开文档时它可能晚一次重绘才出现。
- 编辑面板已在 iPhone 18 Pro 模拟器检查；真机的键盘避让和深浅色切换仍需验收。

## 改代码

`port.patch` 不手改。先建一份可编辑的源码树，在里面改，再重新生成补丁：

```sh
prototypes/ios/dev-tree.sh      # target/ios/dev = 当前桌面源码 + port.patch
# 编辑 target/ios/dev/src/…；新的 iOS 代码尽量写在本目录的 .rs 里
prototypes/ios/make-patch.sh    # 由 target/ios/dev 重新生成 port.patch
prototypes/ios/run-simulator.sh "$device"
```

桌面的 `src/` 变了之后，补丁可能打不上：删掉 `target/ios/dev` 重新建，按报错的位置修。

`Cargo.toml` 关掉了 `gpui-pre` 的调试断言：桌面代码会对同一元素再次设置 hover / active 样式（后设的生效），上游只在调试构建里对此 panic。

调试构建没有优化，换页和滚动会明显发涩；要看真实的流畅度，用 `cargo build --release` 的构建。

## iCloud 空间

有两种使用方式：

- **选择已有文件夹。** 在新建空间或首次创建页选择 iCloud Drive 文件夹，其他设备选择同一文件夹。这个方式只需系统文件选择器授权。安全书签保存在本机的 `quiet-md/space-bookmarks.json`，应用启动时恢复授权。
- **使用应用的 iCloud 容器。** 启动时查询系统授予的容器。在容器可用且已开启 iCloud 云盘的设备上，可在空间设置的「存放位置」中选择「本机」或「iCloud」。应用先保存当前文档，再由系统移动整个空间。位于应用主目录的首个空间暂不支持迁移。

文件传输由 iCloud Drive 负责。应用负责文件协调、外部变更刷新、下载状态和冲突副本保护。

所有空间统一升级 FORMAT 4：逐文档 JSON、列表缓存、本机阅读状态、相对资源路径和旧索引备份见 `docs/FORMAT.md`。旧版本不能打开升级后的空间。首次测试只用新建的测试空间，不要用真实文档库。

2026-11-14 验证记录：`scripts/check.sh` 通过（126 个 core 测试、48 个应用测试，以及指南往返）；桌面临时库迁移、重开、外部更新、未保存编辑保护、数字后缀冲突副本；iOS 编译通过，模拟器显示迁移后的首页和新增的文件夹位置选项。

真机待验收项包括应用容器内空间的双向迁移、跨设备传输、两端离线编辑后的版本冲突，以及重启后外部文件夹授权的恢复。

真机验收只建一个空的测试文件夹：
1. Mac 和 iOS 都把同一个 iCloud Drive 测试文件夹添加为空间。
2. 在两端分别建文档、改名和插图，等同步完成后检查另一端；重启 iOS，检查书签仍能访问空间。
3. 两端断网编辑同一篇测试文档，再联网；确认原文和「（冲突副本）」都保留了内容。
4. 一端保持未保存编辑，再让另一端修改；确认没有静默替换本地编辑，另存恢复副本仍可用。
5. 对尚未下载的文档检查下载提示，下载完成后再打开；不要把未下载状态当作空文档。
