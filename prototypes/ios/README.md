# Quiet.md iOS 原型

原型锁定 `gpui-pre`、`gpui-pre-platform` 和 `gpui-pre-ios` 的 0.3.12。构建脚本把当前桌面源码复制到 `target/ios/stage`，再应用 [GPUI 适配补丁](port.patch)，直接编译整个桌面应用：`Workspace`、文档库、主页、侧栏、搜索、回收站、设置和编辑器都是同一份代码，并通过路径依赖共用 `fdl_core`。桌面 Cargo workspace 继续使用自己的依赖清单。

## 手机上的界面

宽度小于 700pt 时是单栏版式。更宽时走桌面的两栏版式，但 `Info.plist` 还没有声明 iPad，这条分支没有在设备上跑过：

- **按手机的习惯，不是缩小的桌面。** 主页和文档页都没有实心的顶栏：内容顶到屏幕上沿，从悬浮的圆钮和状态栏下面滚过（状态栏下有一道渐隐）。主页和文件夹页是窗口的浅灰底上浮着白色的卡片，页名是大标题，和工具行一起跟着内容滚走；顶上右边是新建文件夹（文件夹页左边是回上一级），卡片一直铺到屏幕下沿。文档页只有返回、目录和「…」三个圆钮；文档标题下面一道细线，紧接正文。打字时文档页右上角换成一个主色的「完成」，点了收起键盘。批量管理时和列表为空时，主页和文件夹页回到固定的标题栏。外壳的菜单（长按卡片或行、文档的「…」）从底部升起成动作面板，占满屏宽，下面压暗。菜单行和侧栏行 44pt，按钮 42pt，字号 16pt。手指抬起后不留悬停高亮。
- **首页是几个去处，不是文档库的平铺（照 Craft）。** 顶栏左边是当前空间的头像（点了去设置），右边一颗玻璃「…」，系统菜单里是「导入」（Markdown 文件、文件夹、DocxXML）和「自定义」。大标题下依次是搜索（「在〈空间名〉中搜索」，高 44 的胶囊）、快速访问（收藏的卡片横向排开，没有时是一块提示）、「所有文档」、可排序的各栏（「文件夹」：顶层的文件夹，带项数；「收藏」：收藏的文档一行一篇），最后一道通栏的线下面是「最近删除」（带篇数）和「自定义主页」。「文件夹」一栏右边的「…」是新建文件夹、折叠 / 展开这一栏；折叠只在这次运行里记着。
- **自定义主页。** 右上「…」的「自定义」或页尾的按钮打开系统的半屏面板（`customise.rs`）：快速访问（最上面那排卡片，横着拖，最多 10 张）选「最近使用」「收藏」或「无」，和下面「收藏」那一栏（列表）各管各的；「所有文档」可以隐藏；「收藏」「文件夹」「标签」三栏可以隐藏、拖动排序（「标签」初始是关着的）。改了马上生效，存在这台设备的 `NSUserDefaults` 里，不进文档库，各空间共用一份。
- **标签（照 Craft）。** 标签是正文里的行内对象（`InlineKind::Tag`，文件里写成 `<cite type="tag">#名字</cite>`）：在正文里打 `#名字` 再打空格或回车就变成标签（名字是各种文字的字母、数字和 `_` `-`；`#` 要在行首或空格后面；标题和代码块里不变），看起来仍是文字，用周围文字的字体和颜色；已有的纯文本 `#名字` 不会自己变，把光标放到它后面打一个空格（或回车）才变。文档库的索引里每篇文档带着它的标签和次数（`Entry::tags`，存盘时算），搜索和卡片预览里标签就是 `#名字`。阅读状态下点一个标签出系统的动作面板：「转到标签」「替换标签」（半屏面板里选一个已有的，或搜一个新名字用它；只换点的这一个）「转为文本」（变回 `#名字` 几个字）；编辑状态下点它只是放光标。首页的「标签」一栏（在「自定义主页」里打开）：标题的箭头进「所有标签」，「…」是「管理固定标签」（半屏面板，一张可搜索的表，点一行固定或取消，行尾打勾）、自定义主页、折叠标签；固定的标签一行一个，点了进那个标签的页，没有固定的时只有一行灰字。固定哪些只属于这台设备，按空间分开。「所有标签」页是浏览页那一套（大标题、搜索、卡片），多一排横着滑的标签胶囊（名字和带它的文档篇数，按名字的码位排；最前面一颗「≡」开所有标签的列表，可搜索，点一个只看它）：点一个只看带它的文档，大标题换成 `#名字`，选中的胶囊排最前、带「×」，后面是这些文档里别的标签；再点一下取消。桌面端能显示、原样存取标签，打 `#名字` 加空格同样变成标签，点了是在文档库里搜 `#名字`，没有标签页。 「自定义主页」里「标签」那一栏的开关同时是整个功能的开关（`tags::enabled`）：关着时打 `#名字` 不变标签，点已有的标签没有菜单，已有的标签原样留着；只看一个标签时卡片标题行末是它在这篇里出现次数的角标。
- **首页的滚动顶栏。** 大标题和搜索随内容滚走，空间头像和「…」钉在顶栏上不动（滚动后头像换成玻璃上面的一个系统视图，免得被玻璃糊掉）；向上滚动后顶部出现原生 Liquid Glass，大号「主页」的文字行完全进入顶栏后，居中的小标题才淡入；往回滚、文字行重新露出时小标题淡出。首页与文档页共用超薄磨砂加原生 Clear 玻璃，柔化经过的文字并保留背景色与边缘折射，底边是一道柔和的渐变高光。仅首页在深色时压低材质亮度，呈接近黑色的薄磨砂，只留微弱透色与底边；文档页保留原来的磨砂玻璃，不做这层压暗；居中的「主页」与首页「文件夹」使用相同的 18pt 系统粗体和文字颜色，不带光晕；文档标题滚出屏幕后也使用这层玻璃，不限于设置了背景的文档。浮层出现时玻璃让开，旧系统仍走原来的版式。
- **浏览页是同一套。** 「所有文档」（整个文档库里所有文档的平铺，不分层，不含文件夹）、「文件夹」（点首页那一栏的标题进，顶层的文件夹）和某个文件夹里，三页长得一样：左上返回，右上「选择」和「…」，大标题和一条搜索跟着内容滚走，下面是原来的网格 / 列表。「…」是一颗系统的玻璃钮，挂着系统菜单，分三组：新建文件夹（所有文档里没有）、宫格 / 列表、排序，当前的那项打勾。「选择」进批量管理：顶上左边是玻璃的「全选 / 取消全选」，中间「已选 N 项」，右边主色的 ✓ 收起；底部换成一条玻璃动作栏（创建副本、移动到、删除），没选东西时是灰的。
- **重命名在一张卡片里。** 手机上没有侧栏，新建文件夹和菜单里的「重命名」在屏幕上方弹出一张卡片，回车或点别处保存。
- **文件夹的图标可以换。** 长按文件夹，菜单里「更改图标」打开一组与默认文件夹同风格的线性图标；新建文件夹的图标菜单共用这一组 SVG，也跟随文件夹颜色。旧 emoji 标识只用于兼容读取，显示时转换为线性图标，无法对应的回退到默认文件夹，不批量改写文档库。选的图标记在文档库索引里（`Meta::folder_icon`，核心库的新字段），首页的文件夹行、文件夹页的标题和搜索结果都用它。桌面版还没有这个入口，也还不在文件夹卡片和侧栏上显示。
- **新建文件夹时可以填描述、选图标和颜色。** 手机上新建文件夹是一张原生的玻璃卡片（`card.rs`）。描述和颜色记在索引里（`Meta::folder_note`、`Meta::folder_color`，核心库的新字段；颜色是文档里用的颜色名）：描述显示在文件夹页的大标题下面，颜色染在列表里的文件夹图标上。建好之后还没有修改这两项的入口，桌面版不显示它们。
- **每篇文档可以有自己的样式。** 文档页「…」›「样式」：文字颜色、字体、纸的颜色、纸后面的背景（纯色、渐变、图片）、分隔符（线、和纸胶带、涂鸦），还有一个样式图库。「字体」页照 Craft：没选的是一排圆钮（Aa / Ss / 00 / Rr，各用自己的字体写），选中的那颗拉长成「字样 名字」的胶囊。样式记在索引里（`Meta::style`），不进文档文件；目前只有手机上能设、能看到。图库依次列出「你的样式」（有保存时显示）、「内置样式」、「Astra 的样式」、「Claude 的样式」和「Neon 的样式」。Astra 和 Neon 的各 12 套均有配套背景、封面和胶带；点选带封面的作者样式只给还没有封面的文档补上封面。改过的样式点「保存」时起名，存在文档库旁的 `styles.json`；卡片长按或底栏「…」可以重命名、删除、设置为默认样式（`default-style.json`，新建文档时由 `Workspace::new_doc` 调 `stylepanel::apply_default` 套上）。

- **文档里配图。** 「/」菜单「助手」下面一组「配图」，点了在键盘位置升起一张原生玻璃卡片（同 AI 写作），只有两样：比例（1:1、2:3、3:2，记住上一次）和图像描述；负面提示词不在卡片上，由画风的排除和设置里的质量排除组成。没有 NovelAI Key 时不开卡片，提示去设置里添加。发送后马上在文档里放一个图片块：「/」那一行只剩「/」就换成图片，还有别的字就插在它后面；块的 `src` 是 `assets/imagine/<id>.png`，同名的 `<id>.json` 记下描述、当时的画风和写到的人物（外貌和排除标签原文）、实际发出的提示词、模型、尺寸和种子。提示词这样拼：人数标签（按写到的人物外貌开头的 girl / boy 数出来，如 `2girls, 1boy`）、画风标签、描述原文、质量词；描述里写到人物的名字或别名（长的优先，英文不分大小写，最多三个），这个人物的外貌标签各占一条 NovelAI 的分角色提示词（`char_captions`），排除标签放在 `v4_negative_prompt` 同一位置的分角色负面词和 `characterPrompts` 的 `uc` 里，几个人的特征不混在一起；人数标签里的 girl / boy 取外貌里第一个性别标签（带权重组的也认）；负面词是画风的排除加上质量排除。图还没回来时块按目标比例占好位置，画一层很浅的底、一条从左往右慢慢扫过的柔光和一个呼吸的图片图标；图回来后占位在图上淡出（先停一下再淡）。NovelAI 同一个 Key 同时只能生成一张（并发会 429），所以几张按顺序排队，切到后台也接着做（`background.rs`，灵动岛显示「配图」）。失败或中断（进程被杀、图没写完）时块里写「生成失败」或「生成已中断」，点按重试。长按生成出来的图弹出系统的上下文菜单（和首页卡片同一套 `menu::context`：图浮起、其余压暗）：生成中只有「取消生成」（删掉这个块）；生成好了有「视图」（和封面菜单的「视图」同一个全屏看图页，从图的位置放大出来；系统菜单先接走长按，所以图的位置每帧记下）、「重新生成」（按原文和现在的模型、画风、人物重新拼，换一个种子和新 id，可撤销）和「查看提示词」（只读的系统页面卡片，分段写描述、人物、画风、提示词、排除，最后一行模型、尺寸、种子；「拷贝」拷实际发出的提示词）；「编辑提示词」用优化的确认页摊开这张图的记录（整理过的用整理结果，没整理过的画面就是原描述、人物是当时发出的提示词和排除），改完点「生成」按改好的重新生成（新 id、新种子、可撤销），不问模型；点按重试则照记录原样再发；失败或中断时有「重新生成」「查看提示词」「删除」。别的图片长按照旧提起来拖。
- **优化描述。** 配图卡片上比例旁边一个魔杖开关（记在 `image.json` 的 `optimize`），开着时发送先问设置 › 文本里的快速模型，把描述按 NovelAI V4+ 的规则整理成 Danbooru 标签：画面（构图、镜头、视角、光线、场景，只写一个瞬间）、每个写到的人物对预设的改动，以及画面要排除的。人物不让模型重写，只让它列「去掉」和「新增」（提示词、排除各一对：`remove` / `add` / `remove_negative` / `add_negative`），由 `fdl_ai::imagine::apply` 在预设上改：没点名去掉的一律原样保留，权重组里只拿掉点名的那个标签（拿空了整组不要），新增的接在后面。提示词里写明角色名、作品名、性别人数标签和外貌特征是身份标签，不许去掉；「不许写名字、作品、人数」只管新增。新增是这一刻的动作表情（`source#` / `target#` / `mutual#` 写互动），去掉只在场景和预设冲突时（场景要求空手就去掉佩剑、在人物排除里加上武器）。整理期间卡片发送键转圈，回来后弹出系统页面卡片「确认提示词」（`imagine_confirm.rs`）：原描述一行灰字（和画面一样就不显示），画面、画面排除是能改的字框；每个人物一张标签卡，上面一组提示词、细线下面一组排除，每组按新增（强调色浅底）、去掉（细边、浅字、删除线）、保留（灰底，预设原顺序，超过 8 个折成「…N」）、「+」排；点保留的变成去掉、再点恢复，点新增的出菜单（编辑、删除），「+」弹输入框，逗号分开是几个，输入预设里有的就是恢复它。权重组拆开显示，不显示权重。点「生成」时各人物按预设 `apply` 去掉和新增，才插块；关掉回到卡片。「编辑提示词」用同一页，人物按现在的预设和记录比出去掉和新增（预设找不到就拿记录的整串当预设）。拼法：人数（按整理后人物提示词里的性别数）、画风、画面、质量词；人物的分角色提示词和排除用改好的（模型漏了的照预设）；画面排除加在画风排除和质量排除之间。人物库里的预设始终不改。整理结果记在记录里，「重新生成」直接用它，不再问模型；「查看提示词」多一段「画面（优化后）」。没选文本模型时打开开关会提示去设置。
- **Liquid Glass。** iOS 26 起，上面这些悬浮的按钮（新建、返回、目录、「…」）是系统的玻璃，折射的是下面滚过的内容，按下会缩一下；长按出菜单和点新建有触感反馈。玻璃跟应用自己的深浅色。更早的系统没有这个效果：仍是原来的实心顶栏、抽屉、标题下的搜索条和纯色的新建按钮。见下面「原生玻璃」。
- **底部面板是浮着的卡片。** 四周留 12pt，圆角 24pt，不描边。没有玻璃时编辑器的面板顶上有抓手：按住往下拖，面板跟着走，拖过 80pt 松手就收起，不够就弹回（`touch.rs` 的 `pull_sheet`）。样式面板和格式面板（原生玻璃，`panel.rs`）也能这样往下拖：子页拖走等于点 ✕ 回上一层，第一页拖走整个收起。外壳的动作面板、键盘上方的各种工具栏没有抓手。
- **给选中的块配图。** 块动作栏里「助手」后面是「配图」（同一个强调色图标）：照选中的块配一张，插在选中的最后一块下面（`Core::insert_generated`，一步撤销，不碰选中的块；最后一块是空段落时排在它前面）。没有 NovelAI Key 或没选快速模型时不开，选中的块里没有字时提示。卡片同「/」配图，只是输入框换成可不填的「补充要求」、没有魔杖，发出一定先整理：`fdl_ai::imagine::passage_messages` 交给快速模型文档标题、所在小节、`<before>`（往上最多 6 块 / 800 字）、`<passage>`（选中的，超过 1500 字留头 600、尾 900）、`<after>`（往下最多 3 块 / 400 字）、`<direction>`（补充要求）；前后文碰到分割线或一二级标题就停，标题写成 `#`、列表写成 `- `，图只给说明，表格、代码在选中的里给开头、在前后文里只留记号（代码不留）。系统提示词在「整理描述」那套规矩前换了开头，后面加一节：前后文只用来认人、认时间地点，只画这一段里的一个瞬间，对话不画字。人物是候选：这一段（和补充要求）里写到的，加上只在前后文里写到的，一共最多五个；模型只把画面里有的写进 `characters`（没改动也要写一个空的），`parse_plan` 的 `strict` 只留这些（最多三个）。之后同样弹确认页；记录多记出场人物的名字（`cast`），「重新生成」「编辑提示词」照它找人物，不再从原文里认；记录的原文是补充要求加这一段压成一行（超过 120 字截断）。
- **块动作栏的格子一样宽。** 放得下就排满一行；放不下时「删除」钉在最右，前面的一排横着滚（露半格出来），栏每次出来从头开始。玻璃上的原生图标和字按滚动区域裁掉露出去的部分（`glass::tile` 带上 content mask），「配音」的原生菜单钮也只留露出来的部分接点按。
- **块动作栏的「格式」**打开的是键盘上方那块「格式」玻璃面板（`format.rs`），手机上没有桌面的块菜单。
- **「/」和「添加」是原生玻璃的命令列表（照 Craft，录屏 2026-11-24）。** 一行 40pt，图标和 15pt 的字，有下一级的行尾一个箭头，露出半行表示还能滚（`cmdmenu.rs`，同一张卡片两处用）。「/」跟在光标下面（下面放不下就翻到上面），宽 272，焦点和键盘留在正文；先分类，点进一类在同一张卡片里淡着换，第一行返回，退格也返回；打了字是平铺的筛选结果，回车用第一条。「/」滚到顶栏下面时不出，点「完成」就收起。跟在字、标点后面也出（桌面只在行首和空白后面；中文词之间没有空格），网址、路径里的和数字后面的（1/2、日期）不出，「、」照旧只在行首、空白后面；紧跟着字的（and/or）回车照常换行，不替人选第一条。块动作栏的「添加」停在屏幕顶上（顶栏那排按钮收起），第一行是筛选框，打开就弹键盘，✕ 或点外面回到动作栏，return 用第一条；插的东西排在选中的块下面，「分栏」「按钮」点进下一级选栏数、类型，「表格」换成底部的尺寸卡片。插完键盘回到正文。iOS 26 之前没有玻璃：「/」是 GPUI 画的卡片，「添加」是底部面板，键盘工具条上方。
- **编辑器的小面板都是原生玻璃。** 提醒、倒计时设置、按钮设置、表情（高亮块和文档图标）、修改编号值、表格尺寸是底部的玻璃卡片，从下面弹上来，后面压暗，点外面、✕ 或往下拖都收起；里面用系统控件（`UIDatePicker`、开关、弹出菜单、输入框），表格尺寸是 9×9 的格子按住拖着选，表情是分类的网格加搜索。「确定」填不对时是灰的。开着键盘打开的，收起后键盘回来；没开的不弹。「@」提及和编号菜单用「/」那张列表，选中文字时工具条上的「类型」「更多」也是，「颜色」是工具条上面的一块玻璃（键盘留着），再点一下同一个钮收起；图片和文件的工具条是贴在块上方的一条玻璃。没有玻璃的系统和宽屏照旧是 GPUI 的面板。
- **文档信息（照 Craft 的「统计」）。** 底部一张原生玻璃卡片，左右各 12pt：完整文档（连嵌套的页面）/ 这一页（现在打开的这一层，不进嵌套的页面）两段，下面一行一个：字数、字符数（连空格）、不包括空格、区块、阅读时间（每分钟 160 字，到秒）、大小、创建时间、最近修改。数法和空间统计是同一个函数（`spaces::tally`）。整页连顶栏的玻璃一起压暗（原生的一层），点外面、✕、往下拖都收起。宽屏和没有玻璃的系统照旧是 `docinfo.rs` 的对话框。
- **过渡。** 进文档、进文件夹（包括子文件夹）、首页的子页、设置的第二级：新页整张不透明地从右边滑入，旧页垫在下面向左退三成屏宽、渐渐变暗。返回时反过来：离开的那一页向右滑出，下面那一页从左边回来、压着的一层暗渐渐褪去。滑着的那一页四角和屏幕一样圆，左边一道阴影，深色下再描一道细边（黑底上看不出阴影）。两个方向都是同一根临界阻尼弹簧（角频率 22，按 Craft 的录屏拟合），松手时接着手指的速度走；动画都在 Core Animation 里，GPUI 只画排好的一页，Metal 视图整个平移（`CADisableMinimumFrameDurationOnPhone` 打开，动画声明 80–120Hz）。点一下进去或返回，等新页真的上屏才开始滑（最多等 90 毫秒）；跟手时等下面那一页真的上屏了才开始跟，免得先露出旧页。从卡片打开的文档返回时不往右滑，而是跟着手指缩小、松手缩回那张卡片再淡出（照 Craft 和系统的缩放转场；卡片这期间空着一格，不在屏幕上就照常滑走）。顶栏和底栏的玻璃钮不跟着页面走，留在原处，滑动一开始就换成新页的：同一个位置的共用一个视图（左上的返回、右上的「…」、右下的「+」），只换图标、大小用弹簧变；首页的头像化成返回钮；只有一页有的，玻璃自己化开或化掉。链接跳到另一篇文档这种平级的换页交叉淡化。首页和设置滚动过、正在换页时，带子还没化开，由 GPUI 自己在顶上画一条平的底盖住滚上去的内容（`veil::plain`），跟着页面走，滑完淡掉。连着换两次页时，前一次一步到位。文档、文件夹、首页的子页、回收站和设置可以从左缘右滑跟手返回：松手过半（或往右甩）就滑走，不过半就滑回来、恢复原来那页（文档回来时键盘不会再弹出）。底部面板（外壳的动作面板、块菜单和它的子面板、工具栏、链接等带输入框的面板）收起时滑出屏幕下沿，下面的遮罩一起淡掉。做法见 `shot.rs`：GPUI 只画当前状态，离开的东西是趁它还在屏幕上拍下的原生快照。
- **不描边，靠明暗分层。** 首页的行、文档卡片、底部面板不画 1px 的边：首页的行直接铺在页面底色上，行与行之间一道缩进的细线，节标题粗体；卡片是文档页铺满的圆角块（网格页边 12pt、间距 8pt）；深色下浏览页是纯黑，文档页是深灰；面板靠填充色和阴影。只在手机版式里这样，桌面照旧。
- **输入 `/` 插入。** 光标附近先显示分类；进入分类后可以返回，继续打字会筛选命令。菜单沿用编辑器的悬浮卡片。
- **链接、公式和代码。** iOS 26 起，链接在键盘上方确认。轻点公式打开独立编辑页，上方实时排版，下方用带行号的编辑器输入 LaTeX。点代码块进入代码编辑页，底部切换语言、复制代码或收起键盘，右上角勾号返回正文。
- **没有悬停手柄，整块的操作在右边。** 页边只有 20pt，块左边的手柄放不下。编辑时，光标所在的块第一行右侧有一个拖动标记（两道短横）：点它选中整块，按住它拖动就是排序。长按一个块直接把它提起来拖（照 Craft，编辑时也是）：没在编辑时不挪就松手是选中这一块；编辑时长按光标所在的块、不挪就松手也是选中它并收起键盘，长按别的块不挪就松手什么都不变；编辑时一拖动，编辑就结束。只读、标题、表格格子里长按仍是选词。落点、拖着的影子和拖到边上自动滚动用的是桌面版原有的那一套。添加和选中整块在键盘工具条上也有。
- **块选择。** 横滑普通段落或长按可进入块选择。点右侧的空心圈加选，点实心圈取消，可以隔行选择。沿右侧选择区向上或向下拖动可加选一段连续的块，同一次拖动折返可缩短范围，靠近上下边缘会自动滚动。正文区域仍可竖向滚动。文字选中时铺底色，图片、附件卡片、子页面卡片、代码和整表使用描边。可裁剪的图片、代码、表格在单选动作栏分别提供「裁剪」「编辑代码」「编辑表格」；多选时可剪切、复制、删除，「格式」直接打开「文字」页，粗体这些、对齐和字体一起改选中的每一块（几块字体不同时哪个都不亮）；右上角「✓」退出。
- **表格。** 单元格中的「⋮」可打开底部工具面板。「编辑表格」插入、移动或删除行列，「选择单元格」切换格、行、列，「格式」调整字形、对齐、字体和填色。主面板可以添加内容、插入公式、切换标题行列和重置列宽。排序按所选列文本进行，保留标题行；带跨行合并的表格不提供排序。
- **选文件、存文件用系统的面板。** 导入在浏览页右上角「…」的菜单里（Markdown 文件、文件夹、DocxXML），导到当前的文件夹；首页右上角「…」的「导入」里也有这三项。手机上导入文件夹只收这一层，子文件夹跳过。「下载为 Markdown」、图片和附件的「下载」先写到沙盒的临时目录，再弹出系统的「存储到」。插入图片和上传封面先问从哪里选：「照片图库」是系统的照片选择器（不用相册权限；HEIC 之类转成 JPEG 再存进文档库），「文件」是只列图片的文件选择器。插入「视频或文件」同样先问：「照片图库」只列视频（照原样拿，不等转码），「文件」什么都能选、能多选。
- **视频在页面里放。** 预览视图的视频（mp4、mov、m4v，小于 100MB 时插入就是预览视图）显示截下的一帧（第 1 秒，短于 2 秒的取开头），点中间的播放就在这一块上放，用系统的进度条、暂停和全屏；滚动时跟着走，滚出屏幕就暂停，键盘弹出时不盖住键盘上的工具条，关了文档、删了块或换了页就停下，放完了回到那一帧和播放按钮。视频下面不挂文件名那一行（截不出画面时才有）。卡片视图的视频点播放、选中后工具条上的「全屏」都是全屏放。主页卡片的缩略图里，预览视图的视频画同一张截帧（`assets/thumbs/…/poster.png`，单独一个文件）和中间的播放按钮；这篇还没打开过、没截过的，主页在后台截好再画（截好之前是文件条）。从页面里那块进全屏再关上时，系统会把 Metal 视图重新提到玻璃那一层上面，`video.rs` 在系统播放器的代理里把它放回去（`shot::reseat_overlay`）。长按视频块（预览视图、卡片视图都行）出系统样式的菜单：「视图」全屏放、「存储到照片」（只要添加照片的权限）、「替换视频」（同样先问照片图库 / 文件，换掉块背后的文件，视图不变，一步撤销）、「卡片视图 / 预览视图」切换、「循环播放」（打勾，记在本机、按文件分，页面里和全屏都循环）、「移除」；视频块因此不再长按提起。别的附件（PDF、Office）在手机上仍没有缩略图，也打不开预览。
- **文字选区。** 双击选词后，键盘上方的平面工具条依次提供颜色、粗体、斜体、删除线、行内代码、链接、公式和收键盘；横滑可找到块类型、下划线和更多。
- **文档面板。** 从目录按钮或「…」打开：一张从底部弹簧升起的纸，后面压暗；点 ✕、点纸外或从标题区（列表在顶端时也可从列表）往下拖都会收起，纸滑回底部。顶上是文档的缩略图（和主页列表行首同一套，由 `editor_panels::mini_page` 算成矩形交给原生层画；有图标时放图标）、标题和「在 <空间> 中」，下面的原生分段切换目录、任务、附件和查找；切换时沿用同一张纸，分段的选中镜片滑过去，下面的内容淡入。目录行用正文字号，当前标题加粗并垫浅灰圆角底，有子标题的行右边是小号折叠箭头。任务和附件为空时居中写一句说明；附件分「媒体」（两列缩略图，后台按尺寸解码）和「文件」。查找行左边是「查找 ⌄」模式菜单（可展开替换栏），右边的选项菜单分两段：文本或正则表达式，以及区分大小写、忽略变音符号和部分匹配。结果按所在标题分组，每条是浅灰圆角卡片，最多两行、命中处加粗；点结果跳回原文，箭头切换匹配项。
- **从主页开始。** 左缘右滑：文档、文件夹、回收站和设置回主页，设置的第二级回第一级。没有玻璃的系统上没有标签栏，侧栏仍是从左侧滑出的抽屉，主页左缘右滑拉出它。
- **安全区。** 顶栏在状态栏之下，内容避开 Home 指示条；键盘弹出时正文和浮层都收在键盘上方。状态栏的字跟着应用的深浅色走。
- **键盘工具条。** 输入正文时可以插入 `/`、打开块格式面板，或在「⋮」中撤销、重做和执行块操作。右端保留粘贴和收起键盘；使用硬件键盘时，工具条贴近屏幕底边。
- **编辑菜单。** 双击选词、只读时长按选词（可继续拖动），或在光标上再点一下，弹出系统的编辑菜单（剪切 / 复制 / 粘贴 / 全选，和别的应用里是同一条，位置和收起由系统管）。阅读模式下长按复制的代码已接上，尚未在模拟器里验证。
- **长按当右键。** 侧栏的行、主页的卡片、回收站的行，原本挂在右键上的菜单都由长按打开。
- **目录** 的按钮在顶栏，列表是临时浮层，选了标题就收起，不记进设置。
- 搜索、「移动到」等对话框按屏幕宽度重排；回收站在窄屏不显示「位置」一列。页边距在窄屏是 20pt。

文档库在应用沙盒的 `Documents/Quiet.md`，首次启动放入「开始指南」。编辑后按桌面的节奏保存，进入后台时立即保存。

新插入的库内资源使用相对路径 `assets/…`，随空间一起移动。读取旧文档时，核心库也能在当前空间的 `assets/` 下查找原沙盒路径已失效的资源。详见[文档库格式](../../docs/FORMAT.md)。

### 原生玻璃

iOS 上 GPUI 的 Metal 画面是不透明的，桌面版「玻璃垫在画面下面」的做法用不了。这里反过来：`glass.rs` 把 `UIVisualEffectView`（`UIGlassEffect`）盖在 Metal 视图上面，折射的就是 GPUI 画的内容。玻璃和系统菜单的按钮放在 Metal 视图旁边、盖在它上面的一层透明视图里（`shot::overlay`，点到空处时它自己不接，触摸照旧落到 GPUI），不是 Metal 视图的子视图：退场的快照只拍 Metal 视图，不能把玻璃也拍进去。由此有三条约束：

- **玻璃上的东西必须是原生视图。** GPUI 画不到玻璃上面，所以图标是把资源里同一份 SVG 用 resvg 画成模板图交给 `UIImageView`，文字是 `UILabel`（系统字体）。带 GPUI 文字或会滚动的内容不适合放玻璃。玻璃菜单是一块作底的圆角玻璃（`glass::panel`）加几行没有自己玻璃的原生图标和字（`glass::row`）。
- **点击仍归 GPUI。** 原生视图不接触摸，点击落到下面同一位置的 GPUI 元素；GPUI 元素里放一个 `glass::pane(...)` 占位，把自己的位置交给同名的玻璃。
- **玻璃永远在最上层。** 抽屉、面板、对话框出现时由 `glass::begin` 全部藏起；元素不在画面里的玻璃在下一帧藏起；换页时等页面滑起来才藏、才换，藏和现是玻璃效果自己撤掉、化开（`Pane::set_shown`），不是调透明度：玻璃压在半透明的图层里会变成一块空的灰胶囊。

**系统菜单**（`menu.rs`）是另一种叠法：出现时的变形、按住滑动时跟手的高亮都是系统做的，自己拼的玻璃做不出来。那个透明按钮自己接触摸，那一小块的点击不经过 GPUI；菜单项的回调来自系统，先排进 GPUI 的主线程队列，再进工作区（`ios::menu_action`）。菜单的样子、朝哪边弹、各项的顺序都由系统定，图标用 SF Symbols。首页「文件夹」一栏的「…」、首页和浏览页右上角的「…」是这样做的；后两者连按钮本身也是系统的玻璃钮，菜单从它里面变出来。封面的菜单（`coveredit.rs`）反过来：透明按钮平时不接触摸，点按或长按封面时由 GPUI 摆好按钮、用 `performPrimaryAction` 弹出；这一下要放到下一轮 run loop，因为菜单弹出时 UIKit 会当场取消手上的触摸，那时还在 GPUI 的事件分发里，取消送不进去，之后的点按就全丢了。

**自己接触摸的玻璃。** 新建按钮打开了玻璃的「可交互」（按下时的拉伸和高光是系统的），上面盖着透明的原生按钮接点击，同样经 `ios::menu_action` 回到工作区。这两处的点击不经过 GPUI。

类名和选择子都在运行时查找，没有 `UIGlassEffect` 的系统上 `glass::supported()` 为假。设 `SIMCTL_CHILD_QUIET_MD_IOS_NO_GLASS=1` 可以在新系统上看旧系统的版式。

### 还没有的

- 「下载为 PDF」和打印在 iOS 上没有。
- 导入文件夹时文件夹留在原地读（向系统要了访问权后不再交还）；其余选中的文件由系统拷进沙盒的临时目录再读。
- 多窗口、快速笔记、打印、自动更新在 iOS 上没有入口。
- 「开始指南」里那张四列的表格，第二、三列之间有一道约 10pt 的缝，原因还没查。
- 依赖悬停或拖动的控件还没有触屏替代：表格的行列手柄、图片缩放、侧栏和主页的拖动排序。
- 主页的标签行、设置页的控件仍是桌面尺寸。导出 Markdown 的设置对话框仍使用桌面版式（对话框里第二个选项在手机上被裁掉）。
- **过渡还差的。** 滑动中途再点返回，前一次直接跳到终点，不会接着速度掉头。工具栏上方的下拉（类型、颜色、更多）出现时没有动画。快照和 Metal 新的一帧是两条路上屏的，往里走和返回都靠等新页上屏来对齐，模拟器上没看到闪，真机上要确认。
- 抽屉不能左滑收起。
- 普通输入时的键盘工具条沿用正文底色。设置的第二级仍是固定的标题栏，内容没有顶到屏幕上沿。
- 文件夹页里没有上级路径（只有回上一级的按钮）；在这个文件夹里新建用底部的「+」（新建文档 / 新建文件夹）。
- 有文件夹的那一层（文件夹和文档混在一起）仍是等高的网格，不是瀑布流。
- 文件夹卡片上悬停才出现的「新建」「更多」两个按钮也不放，对应的操作在长按菜单里。
- 悬浮顶栏比桌面少了两样：文档标题和它前面的上级路径（原来点路径可以去上级文件夹，现在只能返回主页再进）。主页工具行的「批量管理」和批量管理里的「退出」在手机上只剩图标，没有文字；列表视图只留标题和一列时间。
- 目录按钮要等编辑器画过一帧才知道文档有没有标题：在实心顶栏的版式里，刚打开文档时它可能晚一次重绘才出现。
- 编辑面板已在 iPhone 18 Pro 模拟器检查；真机的键盘避让和深浅色切换仍需验收。

## 改代码

`port.patch` 不手改。先建一份可编辑的源码树，在里面改，再重新生成补丁：

```sh
prototypes/ios/dev-tree.sh      # target/ios/dev = 当前桌面源码 + port.patch
# 编辑 target/ios/dev/src/…；新的 iOS 代码尽量写在本目录的 .rs 里
prototypes/ios/make-patch.sh    # 由 target/ios/dev 重新生成 port.patch
prototypes/ios/run-simulator.sh "$device"
```

桌面的 `src/` 变了之后，补丁可能打不上：删掉 `target/ios/dev` 重新建，按报错的位置修。

`Cargo.toml` 关掉了 `gpui-pre` 的调试断言：桌面代码会对同一元素再次设置 hover / active 样式（后设的生效），上游只在调试构建里对此 panic。

调试构建没有优化，换页和滚动会明显发涩；要看真实的流畅度，用 `cargo build --release` 的构建。

## 在 Apple Silicon 模拟器运行

需要 带 iOS 26 或更新 SDK 的 Xcode、已安装的 iOS Simulator 运行时，以及仓库指定的 Rust 工具链。

rustup target add --toolchain 1.99.1 aarch64-apple-ios-sim
xcrun simctl list devices available
device="<现有 Quiet.md Smoke Diagnostic 的 UDID>"

日常构建和冒烟测试共用同一台 iPhone 18 Pro。首次配置时，若设备列表中没有这个型号，可在 Xcode 中创建一台并命名为 `Quiet.md Smoke Diagnostic`。

1. 在 [TestFlight 构建列表](https://appstoreconnect.apple.com/apps/6836195254/testflight)查看本版本已上传的最大构建号，选一个更大的整数。运行仓库检查和 iOS 模拟器冒烟测试。
2. 在已登录开发团队的 Mac 上使用正式版 Xcode、XcodeGen、rsvg-convert、Python Pillow 和 Rust 的 `aarch64-apple-ios` 目标归档。以下命令中的构建号按本次发布填写，开发描述文件名称按本机配置填写。

   ```sh
   export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
   export BUILD_NUMBER="<新的构建号>"
   TEAM_ID=B66GHCCV6S DEVELOPMENT_PROFILE="Quiet md iOS iCloud Development" \
     prototypes/ios/testflight/archive.sh

   ```

   归档脚本打包 Release 真机程序、App Store 图标和对应的 Rust dSYM，验证签名、arm64 UUID 和调试行表。保留每次发布的归档以便解析崩溃。上传脚本使用 Xcode 自动管理分发签名，保留构建号，随包上传符号，并将构建限定为内部测试。使用 Xcode 管理开发签名时可省略 `DEVELOPMENT_PROFILE`。

4. 首次在 iPhone 安装 TestFlight，从 Apple 邀请邮件进入并点「接受」和「安装」。以后从 TestFlight 更新，也可以开启自动更新。每个构建可测试 90 天。

## iCloud 空间

有两种使用方式：

- **选择已有文件夹。** 在新建空间或首次创建页选择 iCloud Drive 文件夹，其他设备选择同一文件夹。这个方式只需系统文件选择器授权。安全书签保存在本机的 `quiet-md/space-bookmarks.json`，应用启动时恢复授权。
- **使用应用的 iCloud 容器。** 启动时查询系统授予的容器。在容器可用且已开启 iCloud 云盘的设备上，可在空间设置的「存放位置」中选择「本机」或「iCloud」。应用先保存当前文档，再由系统移动整个空间。位于应用主目录的首个空间暂不支持迁移。

文件传输由 iCloud Drive 负责。应用负责文件协调、外部变更刷新、下载状态和冲突副本保护。

所有空间统一升级 FORMAT 4：逐文档 JSON、列表缓存、本机阅读状态、相对资源路径和旧索引备份见 `docs/FORMAT.md`。旧版本不能打开升级后的空间。首次测试只用新建的测试空间，不要用真实文档库。

2026-11-14 验证记录：`scripts/check.sh` 通过（126 个 core 测试、48 个应用测试，以及指南往返）；桌面临时库迁移、重开、外部更新、未保存编辑保护、数字后缀冲突副本；iOS 编译通过，模拟器显示迁移后的首页和新增的文件夹位置选项。

真机待验收项包括应用容器内空间的双向迁移、跨设备传输、两端离线编辑后的版本冲突，以及重启后外部文件夹授权的恢复。

真机验收只建一个空的测试文件夹：
1. Mac 和 iOS 都把同一个 iCloud Drive 测试文件夹添加为空间。
2. 在两端分别建文档、改名和插图，等同步完成后检查另一端；重启 iOS，检查书签仍能访问空间。
3. 两端断网编辑同一篇测试文档，再联网；确认原文和「（冲突副本）」都保留了内容。
4. 一端保持未保存编辑，再让另一端修改；确认没有静默替换本地编辑，另存恢复副本仍可用。
5. 对尚未下载的文档检查下载提示，下载完成后再打开；不要把未下载状态当作空文档。
